MYTUBE AI STUDIO — UPGRADE PACKAGE

INSTALL / UPDATE
1. Extract this ZIP.
2. Open your existing GitHub repository: hitaihiss/mytube-ai.
3. Upload and replace the files in the repository root with the files in this folder.
4. Commit directly to main.
5. Wait for GitHub Pages to deploy, then refresh https://hitaihiss.github.io/mytube-ai/

WHAT WORKS
- Create, open and delete projects.
- Save script drafts, character/pet profiles, Story Bible notes and scene plans.
- Reorder scenes.
- Save voice direction per character.
- Save original song briefs and lyrics.
- Plan Shorts.
- Save watermark and Smart Export preferences.
- Estimate export size from duration/resolution/preset (illustrative estimate).
- Export and restore a JSON project backup.
- Dark/light theme and installable PWA shell.

IMPORTANT LIMITATIONS
This is a stronger production-planning prototype, NOT a connected generative AI engine.
No AI script generation, image generation, video generation, voice synthesis/editing, music audio generation, video rendering, MP4 muxing, watermark burning, or actual compression is connected in this package.
Smart Export is settings and an estimate only. The intended final download is ONE MP4 with synchronized video and audio, but that requires a real rendering/export engine.
No API keys are included. Do not put private API keys in browser JavaScript or a public GitHub repository.
Projects are stored in this browser's localStorage. Export backups regularly. Clearing browser data can erase projects. GitHub Pages serves the app files but does not provide a private database or AI compute.
For adapted material, use source material you have permission to use and transform broad ideas rather than copying protected footage, dialogue, characters or music.
